# Retail Segmentation and Clustering

## Description
This project focuses on customer segmentation and clustering to improve marketing strategies and enhance customer experience.

## Dataset
The datasets used in this project include `Online Retail.xlsx` and various CSV files related to customer transactions.

## Installation
To set up the environment, install the required packages listed in `requirements.txt`.

## Usage
Run the Jupyter notebook `Retail- Clustering.ipynb` to execute the analysis and clustering algorithms.

## Results
The project aims to provide insights into customer segments and recommendations for targeted marketing.
