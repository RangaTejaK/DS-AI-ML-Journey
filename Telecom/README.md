# Telecom Customer Churn Prediction

## Description
This project analyzes customer data to predict churn and improve retention strategies for telecom companies.

## Dataset
The dataset used in this project includes customer records and various metrics related to their usage and demographics.

## Installation
To set up the environment, install the required packages listed in `requirements.txt`.

## Usage
Run the Jupyter notebook `Telecom Churn Project - Theory Discussion .pptx` to execute the analysis.

## Results
The project aims to provide insights into customer churn and recommendations for improving retention.
