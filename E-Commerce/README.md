# E-Commerce Analytics

## Description
This project analyzes e-commerce data using the RMF method to understand customer behavior and improve marketing strategies.

## Dataset
The dataset used in this project is `E-com_Data.xlsx`, which contains various features related to customer transactions.

## Installation
To set up the environment, install the required packages listed in `requirements.txt`.

## Usage
Run the Jupyter notebook `E_Commerce Analytics - RMF method_updated.ipynb` to execute the analysis.

## Results
The project aims to provide insights into customer behavior and recommendations for marketing strategies.
