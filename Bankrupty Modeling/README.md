# Bankruptcy Prediction Modeling

## Description
This project analyzes financial data to predict bankruptcy and improve financial decision-making.

## Dataset
The dataset used in this project includes various financial metrics related to companies.

## Installation
To set up the environment, install the required packages listed in `requirements.txt`.

## Usage
Run the Jupyter notebook `Credit_Card_Spend (3).ipynb` to execute the analysis.

## Results
The project aims to provide insights into bankruptcy prediction and recommendations for financial strategies.
