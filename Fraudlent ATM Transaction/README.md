# Fraudulent ATM Transaction Detection

## Description
This project focuses on detecting fraudulent ATM transactions using various data analysis techniques and machine learning algorithms.

## Dataset
The dataset used in this project includes transaction records collected from ATM machines.

## Installation
To set up the environment, install the required packages listed in `requirements.txt`.

## Usage
Run the Jupyter notebooks in the respective folders to execute the analysis and model training.

## Results
The project aims to provide insights into fraudulent transactions and the effectiveness of the detection model.
