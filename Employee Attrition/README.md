# Employee Attrition Analysis

## Description
This project analyzes employee attrition to identify factors that contribute to employee turnover and improve retention strategies.

## Dataset
The dataset used in this project includes employee records and various metrics related to their employment.

## Installation
To set up the environment, install the required packages listed in `requirements.txt`.

## Usage
Run the Jupyter notebook `Employee Attrition (1).ipynb` to execute the analysis.

## Results
The project aims to provide insights into employee attrition and recommendations for improving retention.
