# Liver Disease Prediction

## Description
This project aims to predict liver disease based on various health metrics. The dataset contains records of liver patients and non-patients, with a focus on visualizing data and establishing trends.

## Dataset
The dataset used in this project contains 583 liver patient records and 167 non-liver patient records.

## Installation
To set up the environment, install the required packages listed in `requirements.txt`.

## Usage
Run the Jupyter notebook `Problem_Statement_Liver_Disease.ipynb` to execute the analysis and model training.

## Results
The project aims to provide insights into liver disease prediction and the effectiveness of the model.
