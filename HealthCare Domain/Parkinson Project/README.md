# Parkinson Disease Detection

## Description
This project focuses on detecting Parkinson's disease using various machine learning techniques and health metrics.

## Dataset
The dataset used in this project includes various health metrics related to Parkinson's disease.

## Installation
To set up the environment, install the required packages listed in `requirements.txt`.

## Usage
Run the Jupyter notebooks in the respective folders to execute the analysis and model training.

## Results
The project aims to provide insights into the detection of Parkinson's disease and the effectiveness of the model.
