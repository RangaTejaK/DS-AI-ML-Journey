# Heart Disease Prediction

## Description
This project analyzes health metrics to predict the likelihood of heart disease in patients.

## Dataset
The dataset used in this project includes various health metrics related to heart disease.

## Installation
To set up the environment, install the required packages listed in `requirements.txt`.

## Usage
Run the Jupyter notebooks to execute the analysis and model training.

## Results
The project aims to provide insights into heart disease prediction and recommendations for improving patient outcomes.
