# Credit Card Fraud Detection

## Description
This project focuses on detecting fraudulent transactions using a dataset of credit card transactions. The goal is to analyze the data and build a model to identify fraudulent activities.

## Dataset
The dataset used in this project is `CreditCard.csv`, which contains various features related to credit card transactions.

## Installation
To set up the environment, install the required packages listed in `requirements.txt`.

## Usage
Run the Jupyter notebook `Credit card fradulant.ipynb` to execute the analysis and model training.

## Results
The project aims to provide insights into fraudulent transactions and the effectiveness of the model.
