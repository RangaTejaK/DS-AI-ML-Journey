# Recommendation System

## Description
This project implements a recommendation system using various algorithms to suggest products to users based on their preferences.

## Dataset
The datasets used in this project are `tmdb_5000_credits.csv` and `tmdb_5000_movies.csv`, which contain information about movies and their credits.

## Installation
To set up the environment, install the required packages listed in `requirements.txt`.

## Usage
Run the Jupyter notebook `Recommendation System .ipynb` to execute the analysis and model training.

## Results
The project aims to provide personalized recommendations to users based on their viewing history.
