# Manufacturing Data Analysis

## Description
This project analyzes manufacturing data to identify trends and improve operational efficiency.

## Dataset
The dataset used in this project includes various metrics related to manufacturing processes.

## Installation
To set up the environment, install the required packages listed in `requirements.txt`.

## Usage
Run the Jupyter notebook `Manufacturing DataSet - 16th Oct 2022.ipynb` to execute the analysis.

## Results
The project aims to provide insights into manufacturing processes and recommendations for improvement.
