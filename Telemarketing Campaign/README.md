# Telemarketing Campaign Analysis

## Description
This project analyzes the effectiveness of a telemarketing campaign to predict customer responses and improve marketing strategies.

## Dataset
The datasets used in this project include `bank_telemarketing.xlsx`, which contains information about customer demographics and campaign results.

## Installation
To set up the environment, install the required packages listed in `requirements.txt`.

## Usage
Run the Jupyter notebook `Bank Telemarketing Project.ipynb` to execute the analysis.

## Results
The project aims to provide insights into customer behavior and recommendations for future campaigns.
